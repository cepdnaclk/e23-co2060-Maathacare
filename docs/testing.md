# Testing and results

This page should record **verified evidence**, not assumed outcomes. The repository README discusses unit, API and user-acceptance testing, but does not provide counts, logs or reports sufficient to independently confirm coverage or success rates.

## Testing areas

| Area | Evidence to publish | Status |
|---|---|---|
| Unit tests | JUnit reports / test logs | Add verified results |
| API tests | Postman collections / screenshots | Add verified results |
| End-to-end workflows | Completed scenario records | Add verified results |
| Usability / feedback | Questionnaire and anonymized findings | Add verified results |
| Bug fixes | Issue references and before/after evidence | Add verified results |

## Suggested test-case record

For each case record: identifier, feature, preconditions, steps, expected outcome, observed outcome, result, test date, and relevant screenshot or log.

## Screenshots and privacy

Only share anonymized evidence. Remove names, contact details, pregnancy records and other personal medical data from screenshots.

## Future work

Proposed extensions include improved symptom analysis and risk prediction and richer mother–PHM communication. Clearly identify planned items rather than presenting them as validated features.
