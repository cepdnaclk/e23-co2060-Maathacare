# Mother user manual

This is a documentation template based on the project feature list. Add verified UI steps and screenshots before publishing it as a finalized user manual.

## 1. Getting started

1. Install/open the supported MaathaCare mobile application.
2. Navigate to the registration or sign-in screen.
3. Sign in with the credentials used for your account.

## 2. View appointments

Open the appointment area, review upcoming entries and use the available scheduling controls. **Verify exact screen labels and who is authorized to create appointments.**

## 3. Track symptoms

Open the symptom area, enter the requested information and save it. Check the history section to see previously recorded symptoms. **Confirm actual screen steps from screenshots.**

## 4. Notifications

Check the app's notifications and allow notifications in Android settings if your device asks for permission. Availability depends on the configured backend notification services.

## 5. Pregnancy information

Use the available pregnancy timeline and health-information sections. Do not rely on the app alone to diagnose a medical condition.

## 6. Troubleshooting

- Confirm you have a functioning internet connection when syncing information.
- Check your account credentials if authentication fails.
- Contact the project support team for app-specific issues; add a verified support address here.
