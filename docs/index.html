BEHIND THE PLATFORM

Built on a Connected Digital Architecture

MaathaCare combines React Native applications, a web administration interface, a Spring Boot REST API and PostgreSQL database services.

Backend services are deployed through Railway, while PostgreSQL is hosted using Supabase.
